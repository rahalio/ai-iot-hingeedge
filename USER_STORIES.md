# HingeEdge — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Solution architect

- As an architect, I want a forced checklist before cloud default, so PEMS-like realtime emissions monitoring is not hosted 500 miles away.
- As an architect, I want hybrid placement objects, so historical training can stay cloud while inference is edge.

### Data lead

- As a data lead, I want dataset gates before model build, so we do not implement AI on empty promises.
- As a data lead, I want untapped-data inventory %, so we attack the 60–73% unused data problem.

### Plant manager

- As a plant manager, I want power constraints on edge site cards, so battery sensors are not tasked with continuous AI.

### Compliance officer

- As compliance, I want region-scoped recommendations on the roadmap, so deployments match operating geographies.

### Exception

- As an Experimenter sponsor, I want a supervised pilot path that does not require Pioneer maturity, so we can learn without fake readiness.

### Admin

- As an admin, I want partner access limited to assigned use cases, so strategic roadmaps stay confidential.
